### 0.1 为什么必须先复制到 `/home/hadoop/lab2`（原理，也是报告的"问题与解决"素材）

这台机器上有两个用户：`dryingbox`（uid 1000，我用它写代码）和 `hadoop`（uid 1001，Hadoop 的属主）。
Hadoop 3.3.6 装在 `/home/hadoop/hadoop-3.3.6`，而 `/home/hadoop` 的权限是 `drwxr-x---`（只有 hadoop 自己能进），
**你以 dryingbox 身份根本读不到 Hadoop 安装目录**，`hadoop classpath` 会失败、`hadoop` 命令也不在 PATH 里。

反过来，`/home/dryingbox` 的权限是 `drwxr-x--- dryingbox:dryingbox`（`getfacl` 显示 `other::---`），
**hadoop 用户也读不到我的工作区**，所以「切到 hadoop 用户直接跑我的脚本」也不行。

两侧都堵，所以标准做法是：**用 sudo 把工程复制一份到 hadoop 用户的家目录**（步骤 1），
两边就都能访问了。这也是为什么步骤 1 必须用 `sudo`：只有 root 能往 `/home/hadoop` 里写。

```bash

```

- `jps` 只显示当前用户的 Java 进程，所以**必须在 hadoop 用户下看**，用 dryingbox 看不到。

  `dfs.datanode.data.dir` 里的目录权限不对（`sudo chown -R hadoop:hadoop <datanode目录>`）。
- **不要**随手执行 `hdfs namenode -format`：它会清空 HDFS 里的全部数据。只有 NameNode 从未格式化过时才需要。

## 附录 A　常见报错与处理

| 报错 | 原因 | 处理 |
|---|---|---|
| `ls: 无法访问 '/home/hadoop/lab2': 权限不够` | `/home/hadoop` 是 `drwxr-x---`，dryingbox 进不去（**正常现象**） | 用 `sudo ls -l /home/hadoop/lab2`，或切到 hadoop 用户后 `ls -l ~/lab2` |
| `sudo: 需要密码` / `Permission denied (publickey)` | 需要你输入密码，或免密 SSH 没配好 | 手动输入密码；或用步骤 3 的 `hdfs --daemon start` 系列绕开 SSH |
| `hadoop: 未找到命令` | PATH 没设 | `export HADOOP_HOME=/home/hadoop/hadoop-3.3.6; export PATH=$PATH:$HADOOP_HOME/bin` |
| `找不到符号 / 程序包 org.apache.hadoop 不存在` | 编译时 classpath 不对 | 确认在 hadoop 用户下执行，且 `hadoop classpath` 有输出 |
| `Permission denied: user=hadoop, access=WRITE, inode="/"` | 无权在 HDFS 根目录建 `/lab2` | `HDFS_BASE=/user/hadoop/lab2 bash scripts/run.sh` |
| `FileAlreadyExistsException: /lab2/out/inverted-index` | 输出目录已存在 | `hdfs dfs -rm -r -f /lab2/out/inverted-index`（`run.sh` 已内置清理） |
| `ClassNotFoundException: InvertedIndex` | 没用 `hadoop jar` 或 jar 里没有 class | 必须 `hadoop jar lab2-inverted-index.jar InvertedIndex ...`，先跑 `scripts/build.sh` |
| `java.io.FileNotFoundException: stopwords.txt` | 分布式缓存没生效/路径不对 | 第 3 个参数必须是 **HDFS 上的路径**（如 `/lab2/stopwords.txt`），且先 `hdfs dfs -put` 上传 |
| 作业卡在 `map 0%` 很久 | YARN 资源不足或 NodeManager 没起 | `jps` 看 NodeManager；`yarn node -list` 看节点状态 |
| `Connection refused` 连 ResourceManager | YARN 没启动 | `yarn --daemon start resourcemanager; yarn --daemon start nodemanager` |
| DataNode 起不来 | 数据目录权限/残留 | 看 `$HADOOP_HOME/logs/hadoop-hadoop-datanode-*.log`，必要时 `chown -R hadoop:hadoop` 数据目录 |
